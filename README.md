# Data-201-Project1
My First Project for Data 201

Which model is best at predicting the presence of heart disease? This project goes over four classification models: Logistic regression, LDA, QDA, and KNN. 

The model that performed the best on this specific application was logistic regression for its simplicity, best recall score, and ROC-AUC score. With that, there were limitations of this dataset. The biggest one was that the dataset had identical/duplicate rows due to "over-cleaning", which was done by the handlers of the dataset.
